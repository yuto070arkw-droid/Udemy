# COBOL 読解チェックリスト

## プログラム全体

- [ ] `PROGRAM-ID` でプログラム名を確認した
- [ ] `DATA DIVISION` の有無を確認した
- [ ] `PROCEDURE DIVISION` の最初の文を確認した
- [ ] 終了文が `STOP RUN` か `GOBACK` か確認した

## データ定義

- [ ] `PIC X` と `PIC 9` の違いを確認した
- [ ] `VALUE` 句による初期値を確認した
- [ ] `COPY` 句で取り込まれる項目を確認した
- [ ] `LINKAGE SECTION` の引数を確認した

## 処理ロジック

- [ ] 入力処理がどこにあるか確認した
- [ ] 出力処理がどこにあるか確認した
- [ ] 計算式と計算結果の格納先を確認した
- [ ] 条件分岐の条件と各分岐の処理を確認した
- [ ] 繰り返しの開始条件・終了条件を確認した
- [ ] `PERFORM` や `CALL` の呼び出し先を確認した
