# ワークスペース整理メモ

## 目的

資料が増えても迷わず参照できるように、役割ごとにフォルダを分けて管理する。

## 分類方針

- `docs/`
  運用ルールとチェック観点
- `references/`
  参考書、模試、戦略メモなどの参照資料
- `drafts/`
  作問途中のテキスト
- `data/`
  Excelなどの管理データ
- `export/`
  外部投入向けの出力物

## Excel運用ルール

- 分割Excelは `data/excel/reviewed/` に置く
- マスターExcelは `data/excel/master/` に置く
- ファイル名は `Agile_Q21_30.xlsx` のように範囲が分かる形にする

## 参照資料の運用ルール

- 公式系は `references/official/`
- 模擬試験系は `references/mock-exams/`
- Udemy用の作問戦略は `references/strategy/`

## 補足

- 模擬試験1回目は基礎整理には有効だが、本試験再現度は低め
- Udemy用問題では、参照資料の論点をそのまま出さず、実務シナリオ化して難度を上げる
